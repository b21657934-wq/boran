# БОРАН — промпт для платформы (функциональность, алгоритмы, дизайн)

Сделай веб-платформу «БОРАН» — ИИ-помощник для безопасного пути по зимней Астане. Она работает по одной постоянной ссылке на телефоне и ноутбуке и обновляется через GitHub. Это финальный проект по курсу AI Fundamentals: минимум 3 алгоритма из разных тем курса должны работать по-настоящему, передавать результат друг другу и показывать свои расчёты.

Графика и дизайн — главный приоритет. Платформа должна выглядеть как дорогой продукт: реалистичный 3D-город, живая зима на экране, ощущение «я смотрю на Астану в буран прямо сейчас». Никаких стандартных серых виджетов «из коробки».

---

## 1. ИДЕЯ

- **Название:** БОРАН (KZ: БОРАН, EN: BORAN). Подзаголовок: «Астана. −30. Буран. Дойди безопасно.»
- **Проблема:** зимой в Астане гололёд, накат и буран. Люди падают, получают травмы, мёрзнут на остановках и опаздывают. Опасность скрыта: лёд под снегом не видно.
- **Пользователь:** студент, который идёт из общежития в университет, к остановке или в ТРЦ.
- **Что делает платформа:** по реальной погоде угадывает скрытое состояние улиц, оценивает риск гололёда на каждом участке, строит самый безопасный маршрут и советует, идти сейчас, переждать или ехать транспортом.
- **Язык интерфейса:** RU / KZ / EN (переключатель).

## 2. ФУНКЦИОНАЛЬНОСТЬ (экраны)

**2.1. Заставка (3–4 с, пропускается тапом).** Тёмно-синий экран, косые линии бурана, по стеклу экрана расползается иней. Слово БОРАН собирается из снежинок, затем подпись «Астана · сейчас −27°» с реальной температурой.

**2.2. Главный экран — «Город сейчас».**
- Полноэкранная 3D-карта левого берега Астаны между общежитием и кампусом: реальные здания выдавлены в 3D, в кадр попадают Байтерек и Хан Шатыр.
- Сверху стеклянная плашка погоды: большая температура, «ощущается как», ветер со стрелкой, снег в мм/ч, влажность. Под ней мини-график последних 12 часов, где отмечен момент перехода через 0°.
- Улицы светятся цветом риска (зелёный → жёлтый → красный), как неоновые линии на тёмной карте.
- Поверх карты идёт снег. Его интенсивность и наклон берутся из реального ветра и снегопада.

**2.3. Построение пути.**
- Поля «Откуда» и «Куда»: готовые точки (общежитие, кампус, остановки, ТРЦ) или тап по карте. Плюс время выхода.
- Общежитие и кампус далеко друг от друга (≈ 6 км, больше часа пешком через Есиль), поэтому маршрут бывает двух видов:
  - **пешком** — для коротких путей внутри района (кампус → остановка, общежитие → ТРЦ);
  - **пешком + транспорт** — безопасный пеший участок до остановки, поездка, безопасный пеший участок от остановки. A* строит оба пеших участка.
- Кнопка «Построить».
- На карте появляются два маршрута:
  - **короткий** — тонкая белая пунктирная линия;
  - **безопасный** — светящийся след, который анимированно «прорисовывается» от старта к цели.
- Карточка сравнения: «+3 мин, риск падения ниже в 3 раза, 2 тёплые точки по пути».
- Тёплые точки (ТРЦ, кафе, отапливаемые остановки) отмечены тёплым оранжевым свечением.

**2.4. Совет ИИ.** Большая карточка с одним действием: «Иди сейчас», «Подожди 20 минут — буран стихает» или «Лучше автобус». Под ней одна строка «почему».

**2.5. Панель «Мозг ИИ»** (выдвигается сбоку на ноутбуке, снизу на телефоне). Четыре шага, у каждого: вход → ключевой расчёт → выход → одно предложение объяснения. С мини-визуализациями:
- HMM: столбики вероятностей 4 состояний по часам и линия пути Витерби;
- Байес: «до → после» для выбранной улицы;
- A*: число раскрытых узлов и анимация волны поиска на карте;
- MDP: таблица ценностей действий, лучшее подсвечено.

**2.6. «Я видел лёд здесь».** Тап по карте → отметка (лёд / накат / сухо) сохраняется. Экран «Точность» сравнивает отметки с предсказаниями: доля совпадений и матрица ошибок. Это практическая проверка для раздела Results.

**2.7. Режим «Сценарий» для защиты.** Готовые ситуации: «Оттепель → ночной мороз», «Буран 18 м/с», «Ясно −35°», «Снегопад после оттепели». Выбор сценария подменяет реальную погоду, и вся цепочка пересчитывается на глазах.

## 3. АЛГОРИТМЫ (каждый получает результат предыдущего)

Числа (вероятности, таблицы переходов, награды) задаём сами и подписываем как допущения. Обученная модель не нужна.

1. **HMM: фильтрация (forward) + Витерби — «какое покрытие сейчас».**
   - Скрытые состояния: сухо / свежий снег / накат / гололёд.
   - Наблюдения по часам (из погоды): «мороз без осадков», «мороз + снег», «переход через 0°», «оттепель + осадки».
   - Выход: P(состояние) сейчас и самая вероятная история за 12 часов.
2. **Байес — «опасен ли этот участок».**
   - Prior = P(гололёд) из HMM.
   - Признаки участка: тень от высоких зданий, открытость ветру (широкий проспект, мост), чистят ли (главная улица или двор), рядом остановка (утоптанный накат).
   - Наивный Байес → P(гололёд | признаки) для каждого участка. Это цвет улиц на карте.
3. **A\* — «безопасный маршрут».**
   - Граф улиц: узлы — перекрёстки, рёбра — участки.
   - Стоимость = длина × (1 + α·P(гололёд)) + β·ветер; тёплые точки дают бонус.
   - Эвристика — расстояние по прямой (допустимая). Для сравнения считается короткий путь (Дейкстра или A* без риска).
4. **MDP: Bellman / value iteration — «что делать сейчас».**
   - Состояния: буран усиливается / стабилен / стихает.
   - Действия: идти сейчас / ждать 20 мин / транспорт.
   - Награды: время, риск падения, холод, опоздание. Выбирается действие с максимальной ценностью.

Все числа в интерфейсе, README и Python-ноутбуке должны совпадать. Ответы считает код, а не текст.

## 6. ДИЗАЙН И ГРАФИКА (главное)

**Настроение:** ночная Астана в буран, как в кино. Тёмный город, светящиеся улицы, снег летит сквозь экран, тёплые окна. Интерфейс как приборная панель полярной станции: стекло, иней, точные цифры.

**Палитра (токены):**
- фон-ночь `#070B18` → `#0E1630` (градиент);
- стекло `rgba(16, 24, 48, .62)` + blur 20px, граница `rgba(255,255,255,.10)`;
- лёд-акцент `#9FE3FF`, бирюза фокуса `#3FD0E0`;
- безопасно `#4BE3A0`, внимание `#FFB547`, опасно `#FF5A5F`;
- тепло (тёплые точки, окна) `#FFB46B`;
- текст `#EEF3FF` / `#A9B4D0` / `#6F7A99`.

Дневная тема — светлая морозная (`#EAF2FB`, снег, голубые тени), включается автоматически по реальному солнцу Астаны.

**Шрифты:** Inter (интерфейс, цифры tabular-nums), крупная температура — Inter 800. Акцентные фразы совета — Lora italic.

**Сигнатурные эффекты (изюминки):**
1. **Живой снег** поверх всего (canvas). Скорость и наклон берутся из реального ветра. В буране частицы становятся косыми штрихами, а по краям экрана нарастает иней (CSS-маска с текстурой изморози).
2. **Неоновые улицы:** каждая улица — светящаяся линия цвета риска. При пересчёте цвета перетекают, а не прыгают.
3. **Прорисовка маршрута:** безопасный путь «бежит» от старта к цели светящимся следом с мягким хвостом (TripsLayer), короткий путь гаснет до пунктира.
4. **Волна поиска A\*:** при построении по карте на долю секунды расходится волна раскрытых узлов. Видно, как ИИ думает.
5. **Тёплые точки** пульсируют оранжевым, как окна в мороз.
6. **Термометр-герой:** огромное число температуры с инеем на цифрах, «ощущается как» под ним.
7. **Карточка совета** появляется с мягким «вдохом» (scale 0.96 → 1, blur → 0).
8. **Пролёт камеры:** при старте камера облетает Байтерек, проходит над Есилем и опускается к кампусу на Мангилик Ел (pitch 60°, плавный bearing).

**Интерфейс (mobile first):**
- На телефоне карта во весь экран, панели — bottom sheets со стеклом и ручкой. На ноутбуке — боковая панель справа.
- Кнопки ≥ 44 px, видимый фокус, учитывать safe-area iPhone, уважать prefers-reduced-motion.
- Радиусы 12/16/24, отступы 4/8/12/16/24/32, плавность cubic-bezier(.2,.8,.2,1), 150/220/300 мс.
- Никакого текста поверх карты, который перекрывает маршрут. Подписи не уходят за край экрана.
